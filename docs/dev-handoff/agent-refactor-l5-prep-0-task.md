## 目标

将 L5 准入从“潜在真实临床项目”的单一门禁模型，重新校准为相互隔离的两条轨道：

1. 只面向个人学习、架构实验、测试和安全机制演练，且只使用固定虚构、程序生成或无个人属性技术数据的工程沙盒；
2. 任何真实数据、患者/医师/机构工作流、诊疗决策、公开服务、商业使用、临床评价或人体研究继续 NO-GO，并重新打开原专业门禁。

本任务形成用途与限制声明、重新开门触发矩阵、合成数据政策和只读仓库审计、L5-1～L5-4 沙盒工程设计、受控测试计划、风险与免责声明，并在证据通过后发布但不实施 L5-1 Sandbox 任务。

## 治理状态分类

- `engineering_passed`：工程证据已经验证。
- `sandbox_scope_satisfied`：个人学习沙盒所需条件已经满足。
- `deferred_for_clinical_use`：当前沙盒不要求，但任何临床或公开使用前必须重新打开。
- `external_approval_required`：只有具名专业人员或有权组织才能完成。
- `not_applicable_to_current_scope`：当前沙盒范围不触发；不构成法律结论或永久豁免。

严禁把上述状态写成 `clinical_approved`、法律/隐私/伦理/监管批准或专业背书。

## 非目标

- 不实施 L5-1～L5-4 生产代码或测试；
- 不改变 Legacy、LangGraph、RAG、UI、Domain、数据库或 API 行为；
- 不修改临床红旗规则、阈值、诊疗逻辑或真实处方流程；
- 不采集、导入、复制、生成或使用真实患者、真实病历、可关联个人数据、生产日志或外部聊天记录；
- 不关闭或伪造 G1～G6、EXT-001、EXT-002；
- 不部署、push、合并、公开发布或连接任何真实外部服务。

## 执行约束

1. 主 Agent 是唯一写入者；仓库审计、安全架构、测试设计子 Agent 仅只读报告。
2. 独立 Reviewer 必须未参与写作，并在候选 diff 冻结后只读复核。
3. 仓库数据审计只读执行；发现疑似真实数据、密钥或生产日志时记录脱敏证据，不擅自删除。
4. 对本地 `.env` 等 ignored 文件只报告存在性、分类和暴露风险，不输出值。
5. 旧专业门禁和历史报告保持可追溯；通过新决策和权威索引限定适用范围，不回写成“已批准”。
6. AI 解释不得改写确定性裁决；HITL 只能称为“模拟 Reviewer”或“Sandbox Reviewer”。

## 必须交付

1. 项目用途与限制声明：intended use、excluded use、禁止用于任何个体医疗决定。
2. 沙盒边界和重新开门矩阵：任一触发即停止沙盒准入并恢复适用专业门禁。
3. 合成数据政策：来源、生成方式、版本、摘要、禁止项、疑似真实数据停止/隔离/授权删除流程。
4. 只读仓库审计：数据、密钥、日志、外部数据集、默认开关、部署与真实系统连接边界。
5. L5-1～L5-4 工程包：状态机、信任边界、不变量、失效模式、审计字段和明确非目标。
6. 受控测试计划：正常/拒绝/错误/恢复、fail closed、重放/过期/并发、性能/资源/日志/回退、停止条件与 P0～P3。
7. 风险与免责声明。
8. 独立 Review 无未关闭 P0/P1/P2。
9. 管理台账原子更新；发布但不实施 L5-1 Sandbox 任务。

## 验收标准与命令

1. 实际 diff 仅包含允许范围，且无生产代码、测试、依赖、配置、前端或历史记录修改。
2. 管理六账本、任务、handoff、准入包和下一任务书均 tracked；仓库内 Markdown 相对链接无断链。
3. 当前状态、任务台账、阻塞与风险、决策、验收记录、文档索引对双轨 L5 状态一致。
4. 运行：

   ```powershell
   uv run pytest tests/test_l0_1_contract.py -q -rs
   git diff --check
   ```

5. 若候选 diff 保持纯文档且 L0 契约通过，不要求全量非集成测试；若出现代码/测试/配置变化则立即停止并重新裁决。
6. 独立 Reviewer 对伪造审批、范围绕过、真实数据风险和医疗许可误读进行复核，P0/P1/P2 必须为零或在复核后关闭。
7. 单一管理提交后，工作区和 index clean，并报告 exact HEAD。

## 停止条件

- 发现疑似真实患者/个人数据、生产日志或无法说明来源的数据集；
- 发现无法归属的工作区修改；
- 需要读取/调用真实外部系统、使用凭据或取得外部权限；
- 必须修改生产代码、既有测试、依赖、配置或前端才能证明本任务；
- 必须把范围扩大到真实医疗、公开服务、商业使用或人体研究；
- 独立 Reviewer 存在未关闭 P0/P1/P2。
